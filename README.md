# Прогноз почасовой выработки ВЭС

Решение задачи прогнозирования почасовой генерации ветроэлектростанции мощностью **90,09 МВт** (26 турбин Siemens Gamesa SG 3.4-132, координаты 46,83° с.ш. 38,72° в.д., высота ротора 80 м) на основе метеопрогноза.

**Метрика:** погрешность прогноза X = |S_факт − S_прогноз| / H_уст × 100 %, где H_уст = 90,09 МВт.

---

## Подход и архитектура модели (v8)

### Особенности

- **Эмпирическая кривая мощности** — восстанавливается из обучающих данных как сглаженная зависимость выработки от скорости ветра на высоте ступни ротора. Добавляется как признак `pc_pred` (МВт) — физически обоснованный ориентир без утечки данных.
- **Оптимизация гиперпараметров (Optuna)** — 200 проб TPE-поиска по пространству learning_rate, num_leaves, min_child_samples, reg_lambda, colsample_bytree, subsample. Лучшие 5 конфигураций сохраняются в `optuna_v8.json`.
- **Гомогенный LightGBM-ансамбль** — 5 лучших Optuna-конфигураций × 3 seed = 15 членов LightGBM GBDT с objective `regression_l1` (MAE-loss).
- **Оптимальные веса ансамбля** — веса оптимизируются через `scipy.minimize` (SLSQP, минимизация MAE на val-сплите) вместо простого среднего.
- **Без лагов таргета** — модель не использует прошлую выработку как признак, что устраняет накопление ошибок при авторегрессии и улучшает обобщение на новые данные.
- **Дообучение на полных данных** — после валидации все члены дообучаются на полном датасете с числом итераций `best_iter × 1.15`.

### Состав ансамбля

| Тип | Кол-во | Конфигурации |
|-----|--------|--------------|
| LightGBM GBDT | 15 | 5 лучших Optuna-конфигураций × 3 seed |
| **Итого** | **15** | |

### Признаки (~251)

| Группа | Описание |
|--------|----------|
| Циклические календарные | sin/cos часа, месяца, дня года, дня недели |
| Ветровые компоненты | (u, v)-компоненты на 4 высотах, wind veer между уровнями |
| Физика ветра | v², v³ на каждой высоте; профиль сдвига; прокси hub-height |
| Термодинамика | Плотность воздуха ρ = P/(R·T); ρ·v³; ρ·v³_hub |
| Эмпирическая кривая | `pc_pred` — прогноз мощности по восстановленной кривой мощности |
| Лаги/лиды метео | Сдвиги −1..−48 ч и +1..+6 ч по ключевым переменным |
| Rolling stats | mean/std за 3, 6, 12, 24 ч по скоростям ветра |
| Дополнительные | turbulence_index, icing_risk, pressure_change, precip_total |

## Воспроизводимость

`SEED = 42` фиксируется через `src/utils.set_global_seed` (numpy, random, Python hash). При одинаковых входных CSV и одинаковых версиях библиотек пайплайн даёт идентичный результат.

## Быстрый старт — воспроизведение результата

### Требования

```
Python 3.14 (.venv)
```

### Установка зависимостей

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

### Шаг 1 — Optuna (подбор гиперпараметров)

```powershell
.\.venv\Scripts\python tune.py --trials 200
# Результат: optuna_v8.json
```

Если кэш уже есть (`optuna_v8.json`) — шаг можно пропустить.

### Шаг 2 — Обучение v8

```powershell
.\.venv\Scripts\python train_v8.py
# Результат: models/model_v8.pkl (~10-15 мин)
```

### Шаг 3 — Генерация предсказаний

```powershell
.\.venv\Scripts\python predict.py --model models/model_v8.pkl --out predictions_v8.csv
# Результат: predictions_v8.csv (predict header + 2126 строк)
```

## Формат файла предсказаний

Файл `predictions.csv` для загрузки на платформу:

- Формат: CSV
- Заголовок первой строки: `predict`
- Значения: почасовая выработка, МВт, разделитель дробной части — точка
- Количество строк данных = количеству часов в тестовом периоде

Пример (первые 3 строки):
```
predict
26.671078882207134
24.643066874950087
```
